# B.A.K.E. (Built Applications Kindles Employ)

B.A.K.E. is a collection of optimized mini-applications designed specifically for jailbroken E-Ink e-readers (primarily Amazon Kindle devices). These lightweight apps run on your device via the Kindle Unified Application Launcher (KUAL) and KOReader.

## Application Suite

Below is the current development status of the B.A.K.E. applications:

- **[Inspirational Quotes](https://github.com/FriedVoxelsDev/B.A.K.E):** A daily motivation display (Work in Progress).
- **Clock:** Minimalist, high-contrast timekeeping display (Upcoming).
- **Pomodoro Timer:** Productivity and focus tracker optimized for E-Ink refresh rates (Upcoming).
- **Blinkify:** Speed-reading tool designed for fast text ingestion (Upcoming).
- **Weather App:** Localized climate data and forecasts (Upcoming).
- **ASCII Pet:** A low-resource virtual companion (Upcoming).
- **Task List:** Simple, low-power to-do list management (Upcoming).
- **Hacktime Display:** A customized coder/hacker dashboard overlay (Upcoming).
- **Calendar:** At-a-glance agenda and monthly layout (Upcoming).

## Prerequisites & Installation

To run these applications on your device, you will need the following dependencies installed:

- **Lua(on computer)**
- **LuaGObject(on computer)**
- **Bash(on computer)**
- **GTK(on computer)**
- **KUAL(if running on a e-reader)**

### Deployment Steps (pc)

1. Download or clone this repository to your local computer:
   ```bash
   git clone https://github.com/FriedVoxelsDev/B.A.K.E
   ```
2. Navigate into the `E-Apps` directory to select the specific application folder you want to deploy.
3. Enter the project directory in a terminal utilizing bash(so not PowerShell)
4. Type bash run.sh to run on a computer
5. For an E-Reader(with KUAL), clone the repo, then place the file in your corresponding extensions folder for the device.
